# Database Systems — CSC 261

> University of Rochester · CSC 261 · 2022–2025 · SQL / PHP / HTML

Course repository: projects from CSC 261 at the University of Rochester.

## Course Overview
Fundamentals of database design and use: data models, data description and
query languages (relational algebra, SQL), normalization, transactions,
physical organization and indexing, security, and an introduction to modern
trends (Big Data, MapReduce, NoSQL). Course work is delivered as three
project milestones that culminate in a working PHP-driven web application.

## Topics Covered
- Relational data modeling and ER diagrams
- Schema design and normalization
- SQL DDL / DML and `create` / `load` scripts
- Transactions, indexing, and physical storage
- Building a PHP / HTML front end over a relational schema
- Security and access control for multi-role users
